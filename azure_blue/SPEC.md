# 納品書 → 販売王 使い方

https://demo.yama-gara.com/azure_blue/ を開きます（ログインが必要です）。

1. 「SCAN」で納品書を撮ります。続けて何枚でも撮れます。「SCAN」を押すと、撮影するか、撮影済みの写真（PDFも可。複数ページは1ページ＝1枚）をまとめて選ぶかを選べます
2. 読み取り中はスキャン中の表示になります。終わると、納品書ごとにワイン名・単価・数量・金額が出ます
3. 違う商品が選ばれていたら「変更」で検索して選び直します
   - マスタに無い商品は薄い青になり「新規登録」「変更」が出ます。既存の商品なら「変更」で選び、本当に新しい商品なら「新規登録」で、AIの下書き（フリガナ・略称・イニシャル）を確認し上代・標準売値・売値1を入れて「登録」します
   - 仕入先がリストに無いときは、仕入先の「＋ 仕入先を追加」で販売王の仕入先コードと名前を入れます
     - **同じコード・名前を販売王の仕入先台帳にも必ず登録してください**（ずれると取込エラーになります）
   - 不要な行は右端の × で消せます
4. 注意を確認します
   - 合計本数が12の倍数でないと、納品書の枠が赤くなります。問題なければ「無視」を押します
   - 納品書に印字された税抜合計と合わないと、黄色で表示されます（読み漏れ・読み違いの可能性）
5. 「新規登録」が全部なくなると「CSV」が押せます。新規商品があれば「1_shohin」（商品台帳）と「2_shiire」（仕入伝票）の2つが出ます。販売王には 1_shohin を「商品台帳」形式で先に、次に 2_shiire を「仕入伝票」形式で取り込みます（どちらも「テキストデータ入力」）

## 自動で入るもの
- 伝票番号: 日付＋連番（例 2611020001）
- 伝票区分: 掛仕入
- 支払予定日: 伝票日付の翌月末
- 税率: 10%

一度手で選んだワインは、同じ仕入先の同じ品番なら次回から自動で選ばれます。

## ホーム画面に追加
スマホのブラウザで「ホーム画面に追加」すると、アプリのように使えます。
