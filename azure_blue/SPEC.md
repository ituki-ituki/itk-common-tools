# 納品書 → 販売王 使い方

https://demo.yama-gara.com/azure_blue/ を開きます（ログインが必要です）。

1. 「SCAN」で納品書を撮ります。続けて何枚でも撮れます
2. 読み取り中はスキャン中の表示になります。終わると、納品書ごとにワイン名・単価・数量・金額が出ます
3. 「未選択」（赤）や違う商品は「選択／変更」を押して検索し、正しい商品を選びます
   - 販売王にまだ無い商品は「スキップして、手動で入力する」を選びます（CSVに出ません）
   - 仕入先がリストに無いときは、仕入先の「＋ 仕入先を追加」で販売王の仕入先コードと名前を入れます
4. 黄色の注意を確認します
   - 合計本数が12の倍数でない
   - 納品書に印字された合計と合わない
5. 「CSV」でファイルを保存し、販売王の「テキストデータ入力」で「仕入伝票」形式を選んで取り込みます

## 自動で入るもの
- 伝票番号: 日付＋連番（例 2611020001）
- 伝票区分: 掛仕入
- 支払予定日: 伝票日付の翌月末
- 税率: 10%

一度手で選んだワインは、同じ仕入先の同じ品番なら次回から自動で選ばれます。

## ホーム画面に追加
スマホのブラウザで「ホーム画面に追加」すると、アプリのように使えます。

## 使用トークン
各納品書の下に IN/OUT のトークン数、右上に合計が出ます。
