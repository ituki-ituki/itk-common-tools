# UI

1画面（`frontend/index.html`）。スマホ縦持ち前提。

デザインは azureblue.shop に合わせる: #005B9D / #00375F / 背景 #F7F7F7、見出しは明朝・大文字ラテン・字間広め、細い罫線のみ・影なし・角丸なし。説明文は置かない。タイトルは「納品書 ›› 販売王」（店名は入れない）。

- 下部固定: SCAN（カメラ起動・複数選択可）／CSV
- 撮影ごとに納品書カードが追加され、裏で読み取りが並行で走る
- 解析中は写真の上をスキャンラインが往復し、明細部分はスケルトン表示（ANALYZING）
- カード: 番号・仕入先（プルダウン）・伝票日付／明細（ワイン名、読取原文、単価×数量＝金額）
- ワイン名の右に小さな「変更」バッジ（未選択時は赤の「選択」）。押すと下からシートが出て検索・選択。先頭は「スキップして、手動で入力する」
- 判定の出どころを表示: AI / AUTO（品番学習）
- 未確定の明細は赤背景「未選択」。全部確定するまでCSV出力は押せない
- 警告（黄色）: 12の倍数でない・印字の数量計/税抜合計と不一致・数量×単価≠金額・仕入先未選択
- トークン: カード下に IN/OUT、ヘッダ右に合計
- PWA: manifest・sw.js（素通し）・アイコン（アズールブルーのワイングラス）。入力は16px以上でiOSのズームを防ぐ。safe-area対応
