# API

`/azure_blue/api/`（ログイン必須）

| メソッド | パス | 内容 |
|---|---|---|
| POST | `/scan` | 写真1枚 → 読取＋照合結果（usage付き） |
| GET | `/masters` | ワイン・仕入先の一覧 |
| POST | `/suppliers` | 仕入先を手動追加 `{code, name}`。重複コードは409 |
| POST | `/draft` | 品名 → 新商品の下書き（商品名・フリガナ・略称・イニシャル） |
| POST | `/wines` | 新商品を登録（コード＝数字最大＋1。drafts に保持） |
| POST | `/export` | `[{name, data(base64)}]` を返す。drafts があれば先頭に商品台帳CSV、次に仕入伝票CSV（学習も保存） |

## エクスポートCSV（販売王「仕入伝票(販売王22〜形式)」）

出典: samples/hanbaiou_purchase_format_1.jpg, _2.jpg

- 列の位置で意味が決まる形式。全42列を出し、使わない列は空にする
- 1明細 = 1行。同じ伝票の明細は伝票番号とヘッダ列（1〜20列目）をそろえて並べる
- 改行コードは CRLF。文字コードは Shift_JIS（未確認）
- 見出し行: 出さない（未確認・TODO）
- 画面で確認するのはワイン名・単価・数量・金額のみ。他の列は自動で埋める

| No | 項目 | 値 |
|---|---|---|
| 1 | 伝票番号 | `yymmdd` + 連番4桁（例 `2611020001`）。連番はDBで日付ごとに管理 |
| 2 | 伝票日付 | 納品書の発行日 `yyyy/mm/dd` |
| 3 | 伝票区分 | 2（掛仕入）固定 |
| 5 | 赤伝票指定 | 1（通常） |
| 7 | 仕入先コード | 仕入先マスタから |
| 8 | 支払仕入先コード | 7と同じ |
| 9 | 税率区分コード | 4（10%） |
| 13 | 支払予定日 | 伝票日付の翌月末日 `yyyy/mm/dd`（例 2026/11/02 → 2026/12/31） |
| 21 | 明細番号 | 1〜 |
| 22 | 明細区分 | 1（仕入） |
| 25 | 商品コード | ワインマスタから |
| 26 | 商品名 | ワインマスタの名前（40桁まで） |
| 36 | 数量 | 読み取り値 |
| 38 | 単価 | 読み取り値 |
| 39 | 税区分 | 1（税抜） |
| 41 | 金額 | 税抜金額 |
| 42 | 適格請求書発行事業者区分 | 登録番号ありなら 1 |

それ以外の列は空。

## エクスポートCSV（販売王「商品台帳」）

`backend/ledger.py`。見出し行あり（`商品台帳.項目名`、60列＝A〜BI）、Shift_JIS・CRLF。0/空欄は既定値。

| 列 | 値 |
|---|---|
| 商品コード | 数字コード最大＋1 |
| 商品名・フリガナ・略称・イニシャルキー（カナ/英字） | AI下書き → 手修正 |
| 標準小売単価（上代）・標準売値・売値１ | 手入力 |
| 原単価・標準仕入価格 | 納品書の仕入単価 |
| 商品種別・付箋１・ワレモノ印刷・ナマモノ印刷・販売時/仕入時課税区分 | 1 固定 |
