# wine

ワイン屋さん（1店舗）へのちょっとしたプレゼントとして渡すAIツール。

## 目的

- このお店は「感性を伝えること」を大切にしている。
- ボトル写真とお店のタグから、そのワインのコンセプトが浮かび上がるSNS用の正方形の写真をAIで作り直す。
- 最初の一本は、このお店で買ったワイン（ヴァンクゥール・ヴァンキュ 赤24・白25）で作って見せる。「買わせていただいたワインで作ってみました」という形で渡す。

## 流れ

1. ボトルを撮る（写真はこれだけ）
2. お店のタグの文面を打ち込む
3. 必要なら構図（グラス付き・縦アングル・近接・注ぐ）を選ぶ。画像AIは右上の設定で切り替える
4. AIがタグの感性に合う場面で、ボトルが主役の正方形の画像を作り直す
5. 右上にロゴを重ねた画像を保存する

## 範囲

- 公開・パスワードなし。AIは1日10回まで（全体で）。
- AIの料金は作者負担。Gemini（画像は3.1 Flash Image / 3 Pro Image を切り替え）。
