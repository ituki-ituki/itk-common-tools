# wine

ワイン屋さん（1店舗）へのちょっとしたプレゼントとして渡すAIツール。

## 目的

- このお店は「感性を伝えること」を大切にしている。
- ボトル写真・お店のタグ・飲んだ人の感想から、そのワインのコンセプトが浮かび上がるSNS用の正方形の写真と投稿文を作る。
- 最初の一本は、このお店で買ったワイン（ヴァンクゥール・ヴァンキュ 赤24・白25）で作って見せる。「買わせていただいたワインで作ってみました」という形で渡す。

## 流れ

1. ボトルを撮る（写真はこれだけ）
2. お店の人がタグの味のコメントを数行打ち込む
3. 飲んだ感想を打ち込む（拙くてよい）
4. AIがラベルから銘柄・品種などを読み取り、感性が伝わる短い言葉と投稿文を作る
5. ボトル写真にタグ風の文字（クラフト紙＋手書き風）を重ねた正方形の画像と、投稿文ができる

## 範囲

- 公開・パスワードなし。AIは1日10回まで（全体で）。
- AIの料金は作者負担。モデルは要件が固まってから選ぶ。
