# ワロカ

Walica風の、最もシンプルな割り勘アプリ。

## 概念

- **メンバー**: 割り勘する人
- **立て替え**: 誰が、いくら、誰の分を払ったか
- **精算**: 誰が誰にいくら払えば清算できるか（送金回数をできるだけ少なく）

端数（1円未満）は立て替えた人が負担する。データは保存しない（リロードで消える）。

## 設定

不要。Alpine.jsとフォントはCDNから読み込むため、ネット接続だけ必要。

## 使い方

1. `frontend/index.html` をブラウザで開く
2. メンバーを追加する
3. 立て替えを記録する
4. 精算欄に表示された金額を支払う
