# Phase 1: 割り勘UI（フロントのみ）

## 概要

Walica風の最小割り勘アプリを、`frontend/` のHTML＋JSで作る。バックエンドなし、データ保存なし。
Tailwind CSS・Alpine.js・Font AwesomeはCDNで読み込む。仕様は `docs/UI.md` を参照する。

## やること

- [x] `frontend/index.html` と `frontend/app.js` を作成する（ビルドなし）
- [x] メンバー登録: 追加と削除（記録に含まれているメンバーは削除できない）
- [x] 立て替えの記録: 払った人／金額（円の整数）／誰の分か（初期値は全員）／内容（任意）
- [x] 立て替えの一覧表示と削除
- [x] 精算計算: 均等割り（1円未満は切り捨て、端数は払った人が負担）で、送金回数をできるだけ少なくする
- [x] 精算結果の表示:「A → B ◯円」
- [x] WalicaのUIを踏襲したスタイル（スマホで見やすい表示）

## 完了条件

- [x] ブラウザでHTMLを開くだけで、メンバー登録から精算結果の表示まで一通り操作できる
- [x] 入力例: A・B・Cの3人で、Aが1000円立て替え → B→A 333円、C→A 333円（端数の1円はAが負担）

## 対象外

- グループ作成、URL共有、通貨の切り替え、記録の編集、データの保存（→ Phase 2 / TODO.md）
