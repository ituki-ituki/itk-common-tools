# UI

Walicaの見た目を踏襲する。Phase 1は画面1枚で完結させる。
端末の設定に合わせて、ライト表示とダーク表示を切り替える。
「メンバー」「立て替え」「精算」の見出しには、それぞれ先頭にアイコンを付ける。

## 1. メンバー登録

- 名前を入力して追加する
- 削除できる。ただし立て替えの記録に含まれているメンバーは削除できない

## 2. 立て替えの記録

- 入力: 内容（任意。例：夕食）／金額／誰が払ったか／誰の分か
- 「誰が払った？」はメンバーのバッジから1人選ぶ（プルダウンは使わない）
- 金額は円の整数のみ
- 「誰の分か」の初期値は全員（均等割り）
- 一覧で表示し、削除できる（編集機能はなし）。ゴミ箱アイコンはマウスを乗せると赤くなる

## 3. 精算結果

- 「AさんがBさんに◯円払う」の形で表示する
- 送金回数ができるだけ少なくなるように計算する
- 端数: 1人あたりの金額は1円未満を切り捨て、残った端数は払った人が負担する

## 入れないもの（Phase 1）

- グループ作成、URL共有、通貨の切り替え、記録の編集、データの保存
